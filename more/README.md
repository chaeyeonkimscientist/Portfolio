# Chaeyeon Kim — More / Project Index

Static HTML/CSS/JS implementation of the supplied portfolio reference.

Files:
- `index.html` — markup + project data + interaction logic
- `styles.css` — visual system and responsive layout

Interactions:
- Click any project artifact to load it into the left project viewer.
- Click a collection to filter the project artifacts to that collection.
- Click `Keywords` and then a keyword tag on a project to filter by keyword (the keyword buttons can be extended in `index.html`).
- Project link buttons open the URLs from the supplied Excel workbook.
- The selected project's STAR content comes from the workbook.

No framework or build step is required. Open `index.html` directly or serve the folder with any static web server.
